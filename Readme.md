# File-Backed To-Do List (Python)

This is a simple console-based To-Do List project built with Python. Unlike basic to-do list programs, this version saves your tasks to a file (`tasks.txt`), so your data is stored even after you close the program.

It's perfect for Python beginners looking to practice file handling, loops, and basic app structure.

---

## Features

- View current tasks
- Add new tasks
- Delete tasks by number
- Saves tasks to a file (persistent storage)
- Easy to use via terminal or command line

---

## What I Learned

- Reading and writing text files using `open()`
- Handling user input in Python
- Structuring small programs with functions
- Using lists and loops for task management

---
